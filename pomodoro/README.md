# 番茄钟

一个零依赖、可直接在浏览器里运行的番茄钟：专注计时、任务清单和专注统计。界面适配手机与桌面，支持浅色/深色主题，所有数据只保存在浏览器本地。

## 功能

- **番茄计时**：默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟，每完成 4 个专注进入长休息，全部可配置。
- **专注节奏**：开始 / 暂停 / 继续 / 重置 / 跳过，支持空格、`R`、`S` 快捷键；标签页标题同步显示倒计时。
- **阶段提醒**：专注或休息结束时播放提示音，并在获得授权后发送桌面通知。
- **任务清单**：添加任务与预计番茄数，选中当前专注任务，完成的专注会自动计入该任务。
- **专注统计**：今日番茄数、专注分钟数、累计番茄数和最近 7 天柱状图。
- **设置**：时长、长休息间隔、自动开始、提示音、桌面通知与主题；设置与数据保存在 `localStorage`。
- **无障碍与响应式**：键盘可操作、`aria-live` 状态播报、清晰的焦点样式、尊重 `prefers-reduced-motion`，适配 360px 起的屏幕。

## 运行

需要 Node.js 20 或更高版本（仅用于启动静态服务器和跑测试，应用本身没有依赖）。

```bash
cd pomodoro
npm start
```

浏览器打开 <http://127.0.0.1:4173>。也可以用任意静态文件服务器托管本目录，例如：

```bash
npx serve .
```

> 直接双击 `index.html` 无法运行，因为浏览器会拦截 `file://` 下的 ES 模块加载。

## 测试

```bash
cd pomodoro
npm test
```

测试使用 Node.js 内置的 `node:test`，覆盖计时状态机、设置归一化和统计归档。

## 目录结构

```text
pomodoro/
├── index.html        # 页面结构
├── styles.css        # 设计变量、主题与响应式样式
├── js/
│   ├── app.js        # DOM 交互、持久化、任务与统计渲染

│   ├── settings.js   # 默认值与设置归一化
│   ├── stats.js      # 按日归档的专注统计
│   └── store.js      # localStorage 封装与内存兜底
├── tests/            # node:test 单元测试
├── docs/screenshots/ # 界面截图
├── package.json      # 启动与测试脚本
└── server.mjs        # 零依赖本地静态服务器
```

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 开始 / 暂停 / 继续 |
| `R` | 重置当前阶段 |
| `S` | 跳过当前阶段（跳过专注不计入统计） |

快捷键在输入框聚焦或设置对话框打开时不生效。

## 数据说明

设置、任务和统计分别保存在 `localStorage` 的 `pomodoro.settings.v1`、`pomodoro.tasks.v1`、`pomodoro.stats.v1` 中。清除浏览器站点数据会同时清除这些内容；应用不会向任何服务器上传数据。

## 浏览器支持

使用原生 ES 模块、`<dialog>`、CSS 自定义属性与 `Intl` 无关的本地日期计算，支持当前版本的 Chrome、Edge、Firefox 和 Safari。
